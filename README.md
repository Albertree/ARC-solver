# ARC-Solver
This repository contains the solver implementation of ARC-TBD team.

# Quickstart
1. Clone and navigate to the project folder.
```bash
git clone https://github.com/Albertree/ARC-solver
cd ./ARC-solver
```

2. Open `solver_main.py` and set target task.
```python 
TASK_HEX_CODE = "<hex_code>" # target ARC-AGI-2 task you want to solve. 
```

3. Run `solver_main.py`.
```bash
python solver_main.py
```
