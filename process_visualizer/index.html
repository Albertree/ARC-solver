ⓘ

읽는 법 (how to read)

←/→ (방향키) = 타임스텝 이동
스크롤(wheel) = 패널 내부 읽기 (타임스텝 이동 아님)
타임라인 클릭 = 해당 스텝으로 점프
Esc = 문제 선택으로 복귀
step / substep = 한 step 은 WM 상태 하나다(타임라인 번호 타일 ⓪①②…). 그 상태에서 시작하는 사이클이 substep 이다. 각 substep = (규칙/작용 → 결과) 한 쌍 — view → match→propose → preference→select → compute→apply. 밑줄=mechanism(규칙·작용), 그 뒤=result(변화). SOAR 단계: match·propose=propose, preference·select=decide, compute·apply=apply. 맨 앞 I=input, 맨 뒤 O=output.
권장 흐름: view 에서 ① WM 상태 → match 의 ④ 에서 "어느 operator 가 어떤 조건으로 통과/탈락" (✓/✗) → propose ② 후보 → preference/select ② "왜 이게 골라졌나" → compute ④ 계산 → apply ① +/-/~ 로 "WM 이 이렇게 바뀜".

색 (color)

+ 초록 = WM 에 추가된 항목이다.
- 빨강(취소선) = WM 에서 삭제된 항목이다.
~ 노랑 = 값이 변경된 항목이다.
흐린 회색 = 이번 스텝에 변화 없는 항목이다.
밝은 테두리 = 이번 규칙을 trigger 한 WM 항목이다(발화 근거).
노랑 배경 = 목표(goal)·need 관련 WM 항목이다.
타임라인 색 = 이 타일에서 WM 이 바뀌나? — 파랑 번호=view(상태 머리) ·  진회색 =mechanism(match·preference·compute) ·  연회색 =result(propose·select, 아직 WM 안 바뀜) · teal=apply(WM 변화!) · 보라=descend · 초록=unwind · 검정 I/O. → 색 튀는(teal/보라) 타일이 "WM 바뀐 순간".
※ 그 외 글씨는 무채색이다. 색은 의미 있는 곳에만 쓰고, 제목·operator 이름 같은 강조는 볼드·박스로 표시한다.

화면 구역 (panel)

상단 바 중앙 굵은 글씨 = 이번 타임스텝에 발화한 ARBOR system operator 이름이다.
상단 바 색 태그 = 이번 substep(view·match·propose·preference·select·compute·apply) 이다. step N · ⟨phase⟩ 로 어느 사이클 단계인지 보인다.
④ match = 이 레벨의 operator 를 전부 스캔한 표다 — ✓=조건 통과(후보)·✗=탈락. "왜 이게 떴나/안 떴나"를 여기서 디버깅한다.
① WM = ARBOR 의 working memory 전체이다. 한 줄 = WME (식별자 ^속성 값)이다.
② 발화 규칙 = 발화한 operator 의 이름·소스 경로·설명·trigger 이다.
③ 목표 스택 = 상위→하위 목표 계층이다. 들여쓰기 깊을수록 하위목표이고, 강조줄이 현재 목표다.
④ 탐색/비교 스코프 = 지금 무엇을 비교/탐색하는지다. 위 바는 ARC 계층(TASK→PAIR→GRID→OBJECT)이고 현재 계층이 강조된다.
격자 = train 입력→출력, test 입력→정답, 그리고 현재 조립물(노랑 테두리)이다.
타임라인 = 전체 타임스텝이다.

용어 (term)

operator = WM 상태에 매칭되면 발화하는 행동 규칙이다.
propose→select→apply = WM 읽기 → 선택 → WM 변경의 SOAR 사이클이다.
impasse = 제안할 operator 가 없음이다 → 한 계층 하강한다.
descend = substate push(한 계층 깊이)이다. unwind(복기) = 하위목표 해소 후 상위 복귀다.
frame = 한 노드를 관측해 목표를 '그 속성 찾기'로 구체화함이다.
need = 국소화된 미충족 조건이다. requires = need 를 해소할 효과다(DSL 탐색의 매칭 키).
COMM/DIFF = 비교 결과 같음/다름이다. trigger = 규칙을 발화시킨 WM 항목이다.
anti-unify = 입력↔출력 변화를 원자 조합으로 일반화함이다.

① WMⓘ＋ = 추가 · － = 삭제(취소선) · ~ = 변경 · 흐린 회색 = 동일 / 노랑 배경 = 이번 규칙을 trigger 한 WM 항목 ('규칙·trigger' 단계에서만)

② 발화한 규칙 (operator)

③ 목표 스택 (상위→하위)

④ 탐색 / 비교 스코프

⑤ 격자 (입력→출력 · 현재 조립물)
